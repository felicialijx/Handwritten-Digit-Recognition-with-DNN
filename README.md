## 建立、訓練和評估模型
*(Cell `rQJuryvw7jet`)*

1. **模型定義**：建立一個包含兩個隱藏層（各 $$512$$ 個單元，使用 ReLU 激活函數）和一個輸出層（$$10$$ 個單元，使用 Softmax 激活函數）的 Keras 序列模型。
2. **模型編譯**：使用 `RMSprop` 優化器、`sparse_categorical_crossentropy` 損失函數和 `accuracy` 指標來編譯模型。
3. **資料預處理**：將 $$28 \times 28$$ 像素的圖像展平為 $$784$$ 個像素的一維向量，並將像素值從 $$0\text{-}255$$ 範圍縮放到 $$0\text{-}1$$ 範圍。
4. **模型訓練**：使用訓練資料對模型進行 $$10$$ 個 epoch 的訓練，並設定批次大小為 $$128$$，同時預留 $$20\%$$ 的訓練資料作為驗證集。
5. **基本評估**：使用測試資料集評估模型的損失和準確度。
6. **詳細評估**：使用 `sklearn.metrics` 庫計算並印出分類報告（包含精確度、召回率、F1 分數）和 AUC（曲線下面積）分數。
7. **單張圖像預測**：對測試集中的前 $$10$$ 張圖像進行預測，並印出模型的預測機率和它認為的數字，以及實際的標籤。
